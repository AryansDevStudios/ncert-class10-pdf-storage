# NCERT Class 10 — PDF Storage & CDN Backend

This repository serves as the static asset storage backend for the **[NCERT PDF](https://github.com/AryansDevStudios/ncert-class10-textbooks)** web application.

## 📚 Contents
Contains complete, watermark-free, optimized NCERT Class 10 textbooks across all 6 key subjects:
- **Hindi**: Kshitij-2, Kritika
- **English**: First Flight, Footprints Without Feet
- **Mathematics**: Full textbook, answers, and appendices
- **Science**: Comprehensive Physics, Chemistry, and Biology
- **Social Science**: History, Geography, Political Science, and Economics
- **Information Technology (IT 402)**: Domestic Data Entry Operator, Employability Skills

## 🚀 CDN Access
All files in this repository are delivered globally via jsDelivr CDN:
```
https://cdn.jsdelivr.net/gh/AryansDevStudios/ncert-class10-pdf-storage@main/
```
